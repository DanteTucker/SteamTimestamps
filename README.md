# SteamTimestamps
A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod. 

This makes Resonite automatically add timeline events in the Steam Game Recording feature.
Events are added when:
* You join a session
* You change session focus
* A user joins the session

![A Screenshot of a timeline event in the steam dash](https://i.dant.es/sx/2026-0503-101907.png)

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
1. Download [SteamRecentUsers.dll](https://github.com/DanteTucker/SteamRecentUsers/releases/latest/download/SteamRecentUsers.dll) and place into your `rml_mods` folder. This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default install. You can create it if it's missing, or if you launch the game once with ResoniteModLoader installed it will create this folder for you.
1. Start the game. If you want to verify that the mod is working you can check your Resonite logs.
